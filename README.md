# Libro de Calificaciones
-----------------
22/09/26.  
## Contenido  

Libro de Calificaciones: Devuelve promedio entero, no tiene ciclo y admite siempre 10 valores.  
Libro de Calificaciones: Devuelve promedio decimal, ciclo while, admite calificaciones hasta que se ingrese el valor "-1".  

## Tecnologias  

Lenguaje: C#  
Herramientas: Visual Studio, GitHub, Virtual UTP.
